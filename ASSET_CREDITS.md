# Asset credits and source record

Lore Elements is authored, designed and maintained by Andrew Okoh, with Codex
assistance. This asset pass combines original scripted Blender geometry,
procedural surface work, AI-generated paper artwork and Godot integration.
Generation records describe origin and workflow, not exclusive authorship.

## Original document assets

| Family | Source record in the repository |
| --- | --- |
| Hamina folded dispatch | `notes/rtv-asset-realism-discovery.md`; reviewed v003 Blender checkpoint, procedural paper pixels and selected-object export scripts |
| Four other folded documents | `art_source/folded_documents/provenance-v001.json`; original generated atlases and a UV-only derivative of the original Hamina mesh |
| Torn notebook | `art_source/notebook_page/provenance.md` and `export-handoff-v001.md`; original atlas and optimized closed Blender mesh |
| Clinic card and school triage tag | `art_source/triage_card/provenance-v001.json` and `identity-provenance-v001.json`; original stock/ink surfaces and punched-card geometry |
| Six report and posting identities | `art_source/report_sheet/provenance-v001.json` and `identities-v001/provenance.json`; original sheet, torn-edge and layered variants |
| Crayon map | `art_source/crayon_map/provenance-v001.json`; original generated drawing and handled-sheet geometry |

Inventory renders derive from these assets. Reader backgrounds reuse their paper
stock, including the blank triage-stock reverse. The canonical story remains
the dynamic reader text; small surface excerpts are not a substitute for it.

## Native references

Road to Vostok and its original assets are copyright Plumato Games. Damaged Field
Note and fallback presentation reference the native Patient Report at runtime.
Native scripts, shaders, sounds and fallback art are resolved from the user's
installed game. The mod package does not include extracted native models,
textures, game scenes, engine binaries or a game pack.
